Kurulum Rehberi

Bot + panel kurulumu adım adım.

1. Botu çalıştırma (VDS)
pip install discord.py flask
python main.py

main.py üstündeki TOKEN, DISCORD_CLIENT_SECRET ve PANEL_SIFRE alanlarını doldurun. İlk açılışta slash komutların listeye düşmesi 1 saati bulabilir.

2. Paneli bağlama

Bot & Api Ayarları → Panel API Adresi kutusuna botun adresini yazın (https://....trycloudflare.com/api/applications). Site girişinde şifrenizi kullanın.

3. Komut listesi

/etkinlik_ac • /etkinlik_kapat • !etkinlik_sil • /oncelikli_kanal • /onceliksiz_kanal • /verilecek_rol • /karaliste_ekle • /karaliste_sil • /karaliste_liste • !kayit_istatistik

4. Sorun giderme

Önce Bot & Api Ayarları → Bağlantı Testi + Sistem Kontrolü çalıştırın. 401 = tekrar giriş yapın. 403 = anahtar/şifre yanlış. Zaman aşımı = bot kapalı ya da tunnel adresi değişmiş.
